# Privacy Policy

Last updated: May 22, 2026

YAP Lamp Design is a browser extension for YAP UI customization.

## What the extension does

The extension modifies the appearance and behavior of supported YAP pages in the user's browser. It applies local interface customizations such as layout changes, filtering, grouped highlighting, and settings-driven UI adjustments.

## Data collection

The extension does **not** collect, transmit, sell, or share personal data with the developer or with third parties.

The extension does **not** use:

- analytics services;
- advertising identifiers;
- tracking scripts;
- telemetry backends;
- external developer-controlled servers for user data.

## Data processing

The extension reads and modifies page content locally in the browser in order to provide its functionality on supported YAP domains.

This processing happens locally on the user's device and is not sent to external services by the extension.

## Local storage

The extension stores its own configuration and preferences locally in the browser using the browser extension storage APIs.

Examples of locally stored data include:

- UI preferences;
- filter settings;
- extension behavior options;
- imported or bundled configuration values used by the extension.

This stored data remains on the user's device unless the user exports it manually.

## Third-party services

The extension does not send user data to third-party services.

## Contact

Use the browser store listing support contact for questions about this extension.
