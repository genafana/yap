Файл config.json
Все значения параметров (за искл. true/false) должны быть в двойных кавычках.
Все параметры разделены запятой.
Если тут что-то случайно "сломать", конфиг "работать" не будет, при этом будут использованы значения по умолчанию.

Настраиваемые параметры:
"nik_on_top": true - ник выводится над аватаркой, false - под ней
"nik_on_topleft_col_width": ширина левой колонки (в em) в ленте сообщений
"left_col_right_border": линия, отделяющая левую колонку в ленте сообщений, в формате css (толщина тип цвет)
"user_pic_size": размер стороны (для прямоугольной - наибольшей) аватарки в пикселях
"title_bg_color": цвет фона строки заголовка и левой колонки
"message_bg_color": цвет фона сообщения в ленте
"citate_bg_color": цвет фона цитаты в ленте (вдруг кто захочет отделить от сообщения, но не рекомендуется)
"show_date_or_age": показывать дату регистрации и период на сайте, допустимые значения - date, age
"self_highlight_bg": цвет фона "плашки юзера" для пометки собственных сообщений в ленте ("" - нет)
"self_highlight_border": линия границы "плашки юзера" для пометки собственных сообщений в ленте ("" - нет)
"reduce_ad_block": уменьшение ширины правого столбца на 20% (на больших мониторах не рекомендуется), true - да, false - нет
"msg_menu_type": тип меню в сообщениях, "icon" - иконки, "text" - текстовое
"origin_scroll_top": настройка оригинальной ссылки "Наверх"; "" - не настраивать, "hide" - скрыть, "moveleft" - переместить ближе к правому краю ленты
"response_form": вывод формы быстрого ответа (ФБО); "always" - всегда, "toggle" - по кнопке "Показать / скрыть ФБО" (не занимает место на экране, когда она не нужна)
"apply_context_menu": использовать контекстное меню в ленте; true - да, false - нет (то есть, если только отвлекает, можно отключить)
"smilies_show_all": выводить весь набор смайликов на ФБО; "always" - всегда, "simple" - только в простой ФБО (не в расширенной), "" - не выводить
"smilies_text": выводить текстовый эквивалент смайла; "bottom" - снизу смайла, "title" - как всплывающую подсказку, "" - не выводить
"smilies_columns": кол-во столбцов при выводе всего набора смайлов; допустимый диапазон 2-5 (значение вне диапазона воспринимается как 2)

После смены значения любого из параметров (и сохранения изменений файла!) плагин перезапускать не требуется, достаточно обновить страницу в браузере.
