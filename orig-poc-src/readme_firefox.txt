Перед началом важно понимать разницу:

Stable - обычный Firefox (самый строгий)
Firefox ESR - корпоративная версия
Firefox Developer Edition - для разработчиков
Firefox Nightly - экспериментальная

Это важно, потому что неподписанные расширения работают не везде

1. Подготовка расширения
Шаг 1. Распаковать архив
Распакуйте файлы расширения из архива (RAR/ZIP)

Шаг 2. Проверить/подготовить manifest
Если есть файл manifest_ff.json, переименовать в manifest.json с заменой файла.
(!) Находящийся в архиве manifest.json предназначен для chromium браузеров, поэтому его следует заменить.

Шаг 3. Создать ZIP-архив
(!) Самый важный момент
Нужно заархивировать только файлы, без папки.
Правильно:

manifest.json
script.js
style.css

Неправильно:

my-extension/
manifest.json

Шаг 4. Переименовать в XPI. После создания архива:

my-extension.zip - my-extension.xpi

.xpi - это просто ZIP для Firefox

2. Установка ПОДПИСАННОГО расширения (самый простой вариант)
Если уже есть подписанный .xpi:
в адресной строке - about:addons
Нажать "шестерёнка"
Выбрать "Установить дополнение из файла...", выбрать имя_файла.xpi

Всё - работает в ЛЮБОЙ версии Firefox

3. Установка НЕПОДПИСАННОГО расширения

Вариант A - ESR / Developer / Nightly (постоянная установка). Работает в:

Firefox ESR
Firefox Developer Edition
Firefox Nightly

Шаг 1. Открыть настройки about:config, нажать "Принять риск".
Шаг 2. Найти параметр xpinstall.signatures.required изменить его значение true - false
Шаг 3. Установить расширение. Для этого открыть about:addons,
"шестерёнка" - Установить из файла и выбрать имя_файла.xpi

Теперь расширение установится и будет работать постоянно

Вариант B - Stable Firefox (временная установка)

В обычном Firefox отключить подпись НЕЛЬЗЯ. Единственный вариант установки — режим разработчика.
Для этого открыть about:debugging, перейти "This Firefox", нажать "Load Temporary Add-on",
выбрать manifest.json (если архив распакован) или имя_файла.xpi.

(!) Ограничения
(!) расширение исчезает после перезапуска
(!) нужно ставить заново каждый раз
4. После установки — включить доступ к сайту

Открыть:

about:addons
Найти расширение
Перейти:
(!) Разрешения
Включить:
Доступ к данным для https://www.yaplakal.com и https://www.yap.ru
